# 普通怪物像素图集

- 输出：`public/assets/demo/monsters-v2.png` 与 `src/data/monsterArt.ts`（生成文件，不要手改）。
- 重新生成：`python3 art-src/monsters/build_monsters.py --preview <预览目录>`（只需 numpy 与 Pillow）。
- 来源与许可：Claude 原版、GPT 在 #100 中精绘，使用本目录脚本逐像素绘制，全部为本项目原创形象，无第三方素材，可随游戏商用、修改与分发。
- 画法：1 个图集像素 = 0.5 个游戏像素（与大肥鱼同一颗粒密度）；1 像素黑描边、两到三档硬边明暗、亮色，整体参考元气骑士。默认朝右，游戏里按朝向翻面。

## v2 生成规则（#100 / ADR 0037）

主体增加腹部色块、分层眼睛和材质细节；金属桶增加铆钉/把手/划痕，蛙卵增加透明壳内的胚胎。所有形状在原生像素网格上重画，不缩小整屏或对位图做平滑插帧。

`PIVOTS` 记录不含透明边距的身体中心，与玩法半径分离；`FRAME_PAD` 和 `FRAME_BOTTOM` 为引信、旋转、压扁及死亡烟团留白。生成时检查所有帧非空且不碰边。待机/行走补中间帧并同步缩短帧时间，循环长度不变；完全相同的栅格帧共享图块，避免重复占用纹理内存。

图鉴直接读取注册表，无需另导出静态 PNG。全部动作清单和前后对照见 [验证记录](../../docs/testing/monster-art-v2.md)。
