# 同系列地图素材：可复用生成 prompt

当前固定参考：`sources/ground-<theme>-v7.png` 的地板块面与主色、`sources/wall-variants-v19-approved.png` 的既定造型；当前同类 v4 图只补充物件身份。不要用旧 v18/v3 或被否决草稿作主要风格参考。

完整本批调用记录见 [generation-records.json](unified-v4/generation-records.json)。布局图和设计尺寸见 [manifest.json](../layouts/v4/manifest.json)，它们是绘制引导，不能充当测量后的运行帧。内置 imagegen 最多附五张参考图，明确每张用途；需要逐主题参考时分批生成，不通过反复引用新草稿造成偏移。

## 通用模板

```text
用途：为《AI娘大战奶蛙》扩展同系列俯视角像素地图素材。
本次主题：[主题名称/ID]；类别及数量：[完整列表和状态]。
参考1：[该主题 ground-v7 或新主题已确认地板]，决定底色、安静的像素块面和纹理密度。
参考2：wall-variants-v19-approved.png，决定整套造型、浅倒角、亮顶暗面。
参考3：[当前同类别源图]，只决定模型身份、朝向、状态和锚点。
参考4：[按实际模型比例制作的几何布局]，只决定画幅和内部构件比例。
主材/地板主色：[填写]；暗面：[填写]；局部交互色：[填写]。
正交俯视、可见正面；轴对齐，不是菱形等距视角。清楚且中等偏细的像素色块，
哑光、低饱和背景材质、少量磨损，薄材质色外缘；不加厚黑外框、贝壳、密集噪点、
写实纹理、模糊滤镜、塑料高光或大范围柔光。统一左上受光，不能旋转整块资源改变光照。
完整帧尺寸：[W×H]；内部构件尺寸：[具体填写]；锚点：[填写]。
先满足模型实际比例，保留合理透明留白；不为铺满画幅拉宽或压矮物件。
不同状态共用帧尺寸、原点、底座轮廓和坐标，只改变状态所需部件。
独立物件外部真实透明，无黑色底板，无文字、标签、水印或额外场景。
[插入下表类别硬约束。]
```

## 新主题配套清单与验收

每主题必须含三墙、十地板、四方向开锁八门、一障碍、一边框、**一水晶与地刺三态**，共27项主题资源。水晶/地刺不能只生成一套通用石殿底座。共享桶、宝箱、地雷、补给等可复用当前风格。

生成后逐项检查数量、材质色、状态与锚点；用 alpha 内容边界测量实际尺寸，不相信提示词已自动实现精确像素。代码只做等比缩放；需要补画时返回 imagegen，不能分段扭曲顶面、墙身或门。当前已确认源图存在轻微比例误差，运行时完整模型采用统一倍率并裁掉少量超出模块的外缘，不改变原稿。此为接入处理，不是未来绘制可忽略比例的理由。

保留原始PNG、完整prompt和SHA-256；无损WebP解码RGBA逐像素一致、单文件小于2MiB。新增帧必须注册主题路由，并检查换房/换层/同版本读档。墙体与地板随机分别派生表现流，不能消耗玩法随机或新增存档字段。最终按相同世界尺寸看整房、门墙接缝、危险边界和移动镜头；源图看起来正确不能代替局内验收。


当前布局接入约束（#139 复审后）：障碍按完整方形模型重复，布局实际长边为短边整数倍；地刺实际宽高均为16的整数倍。不能裁掉模型末端或只改显示大小；布局尺寸同时驱动碰撞/伤害。新尺寸须检查可行动面积、连通与入口净空。


#115 布局补充：素材属于风格而不是第几层，同一风格可用于任意楼层。45°斜墙仍使用上面的完整正交墙块，沿斜线连续放置，不新增旋转/拉伸斜墙贴图。起点/武器/终点的正方形尺寸由布局决定，不能重绘资源来掩盖比例问题；终点不添加地面文字。机关摆放必须计入完整底座与外扩边框，不能互相重叠。资源本身不包含房间布局或摆放算法。
