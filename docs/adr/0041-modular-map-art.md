# ADR 0041：模块美术与原矩形可行动面积下限

状态：已实施；Claude review 5686698325 对旧 head `f386549` 无代码阻塞。负责人否决初版墙体画面后的改动需增量复审与画面/真机验收。承接 #114、ADR 0039/0040；不启动 #115 的百房内容库。

## 决定

负责人补充要求新房间的绝对可行动面积至少相当于原矩形。基线为 #132 前 main `60c35eb` 的冻结 legacy_v1，对应原障碍和未破桶一起比较；不是 #132 已缺角的灰盒，也不以装饰区域补足。

前三主题的外包框从 `(104,47,272,176)` 扩为 `(96,39,288,192)`，中心仍 `(240,135)`。东北/西南缺角和深渊凹口向外调整，内部已有障碍/机关坐标沿用。奶池与 Boss 四柱保留原矩形。空房轮廓面积分别为石殿 53,760，沉船/深渊 53,248，奶池 47,872 平方世界单位。

`compileRoom` 返回从实际 boundary 求出的 bounds。一个会话独占同一个可变 bounds 对象，传给 CombatWorld、CombatBridge 与 RoomDirector；切房前同步 Arcade world bounds。导航预分配扩展外包框，实际 free/sweep 由本房轮廓裁定。ports 沿真实外包边生成，入口仍向内缩 24；北门 x 与原模板约定一致，深渊仍为 168。原障碍以旧中心换算，不随外包框左上角平移。

验收同时要求：地形可通行比例 ≥80%；玩家中心可达/同轮廓空房中心面积 ≥80%；每房障碍扣除面积及玩家中心连通面积均 ≥ 对应 legacy_v1；所有适用怪物半径连通，四向门口有净空。测试同时计入未破桶。常规 2 单位采样、额外 0.5 单位复核均为数值近似，非解析几何证明。

## 美术接入

- 七张共享图集：原地形、上下门、机关/物件，加上 v2 地板、独立障碍、独立完整墙体模型与左右侧门。原 PNG 与完整提示词留在 art-src，运行时 lossless WebP 解码 RGBA 完全相同，各 <2 MiB。地板以镜像重复匹配边缘像素，没有修改原始 PNG。
- 墙体按负责人最终规格独立绘制，以门的像素精细度为基准；负责人已接受 v12：顶部浅纹与墙身区分，适当简化颗粒、略加强像素感，外轮廓平直、边线不使用浓黑框。原 PNG 已是顶部与下部相连的一体模型，未拼接旧素材。原图比例是美术近似，导出记录同一完整模型的顶/身采样区；渲染器以最近邻采样组装成严格 80×80 顶部和 80×96 墙身，墙身高/宽为 1.2，顶部另算。实心方形底色保证顶部外轮廓整齐，纹理与装饰限制在方形内部，不添加越界的墙顶摆件。
- 实际墙块占地为轮廓外侧 8×8，墙身投影高 9.6，固定 y/x 绘制，同一个直立模块用于横排、纵向覆盖和凹凸角。墙体底座占地在物理轮廓外；前墙顶部可向上覆盖其后方地板的画面，角色、弹体与危险提示继续画在烘焙地面之上，保持可读性，不改变可行走区域。
- 保持一张 2624×1856 CanvasTexture（每世界单位 8 像素，与门的材质密度接近） 与 16 个障碍 TileSprite；另有同尺寸离屏墙层及四个 80×176 模块缓存。只在建房时烘焙，门位在独立墙层完整留空，保留底下地板。上下门原图、40×30 显示尺寸与 origin 不变；新左右门使用独立图集，13×38、沿法线向外偏 6，让方形门柱与墙带对齐。门触发、入口、物理和开锁状态不变。
- 机关平齐边沿沿原 footprint 烘焙。水流/海草重复间距为 32、地刺为 16；障碍按完整块排列，使用 blocks-v2，不复用于墙体。伤害区、碰撞、计时和状态仍由既有 sim 决定。奶池地板降低亮度，区分奶白 Boss 提示。
- 正式 DemoSession 接入 RoomArt，部署后替换 #132 的线上灰盒；主城复用石殿材质。整套模块素材缺失时按真实轮廓回退灰盒，模块门不依赖旧 ART.doors，宝箱/出口单独检查物件图集。旧图片及 LegacyRoomArt 暂留，清理另按负责人队列执行。
- 不改变相机居中、缩放、角色大小、房间拓扑与每层房数。当前仅支持规定外包框内、8 单位网格对齐的轴对齐轮廓；偏网格或直接斜边明确拒绝。更多房型/45° 墙留 #115；届时逐格斜排同一模块，但斜墙不设置门。每主题 200 个测试布局只验证组合复用，不进入生产候选库。

## 行为与存档

房间扩大使出生候选、随机采样接受率、外墙碰撞位置和走位距离发生变化，不能承诺新旧版本相同 seed 的出生坐标或整场 RNG 相同。中心、旧障碍和 Boss 房尺寸保持；同版本恢复必须精确一致。更新指纹覆盖 src/public，本次上线仍按 #132 结束旧冒险并返回菜单，保全天赋点、已购天赋及局外档案，无跨版本战斗迁移。

沿用 #132 已被武器负责人接受的外墙行为：弹跳弹撞墙消耗反弹次数、回旋镖折返、光束止于墙。此次前三层外墙位置变远，会相应改变撞墙/折返距离与光束可达长度；没有修改 Arsenal/AI 代码或数值，但不能写成武器行为完全不变。负责人试玩仍需留意外墙手感。初版证据见 [历史记录](../testing/modular-map-art.md)，墙体复修、实际近景和性能限制见 [新记录](../testing/wall-art-v2.md)。
