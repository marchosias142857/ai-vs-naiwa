# ADR 0041：模块美术与原矩形可行动面积下限

状态：已实施，等待当前 head 的 Claude 复审。2026-10-28 最新：负责人接受除地板外的 v3 资源，已选定 ground-v4 地板（以 v3 不规则地砖为基础，去暗边/黑框、略提亮、砖缝平移连续且不镜像），要求上传后恢复 Claude 复审。本次明确免跑验证和实机截图；旧测试、性能及截图只能作为历史。等待新 head 交叉评审时保持 Draft，通过后按 AGENTS 交负责人合并；不改 main、不触发远端 CI。

## 决定

负责人补充要求新房间的绝对可行动面积至少相当于原矩形。基线为 #132 前 main `60c35eb` 的冻结 legacy_v1，对应原障碍和未破桶一起比较；不是 #132 已缺角的灰盒，也不以装饰区域补足。

前三主题的外包框从 `(104,47,272,176)` 扩为 `(96,39,288,192)`，中心仍 `(240,135)`。东北/西南缺角和深渊凹口向外调整，内部已有障碍/机关坐标沿用。奶池与 Boss 四柱保留原矩形。空房轮廓面积分别为石殿 53,760，沉船/深渊 53,248，奶池 47,872 平方世界单位。

`compileRoom` 返回从实际 boundary 求出的 bounds。一个会话独占同一个可变 bounds 对象，传给 CombatWorld、CombatBridge 与 RoomDirector；切房前同步 Arcade world bounds。导航预分配扩展外包框，实际 free/sweep 由本房轮廓裁定。ports 沿真实外包边生成，入口仍向内缩 24；北门 x 与原模板约定一致，深渊仍为 168。原障碍以旧中心换算，不随外包框左上角平移。

验收同时要求：地形可通行比例 ≥80%；玩家中心可达/同轮廓空房中心面积 ≥80%；每房障碍扣除面积及玩家中心连通面积均 ≥ 对应 legacy_v1；所有适用怪物半径连通，四向门口有净空。测试同时计入未破桶。常规 2 单位采样、额外 0.5 单位复核均为数值近似，非解析几何证明。

## 美术接入（v3，取代此前保留原上下门的决定）

负责人最终接受 v17：大正方形中央有小正方形凸起，明亮顶部与显著压暗的墙身，清楚的像素材质、平直轮廓、无浓黑框。本轮墙体 PNG/WebP 不变；以它为参考重新生成其余全部地图美术，没有用旧模型拼接。

- 九张共享原图/无损 WebP：v17 墙体、四主题地板、四主题障碍、上下门、左右门、机关与交互物、四主题嵌地边框、主城/补给、环境危险区。完整清单与状态见 [素材说明](../../art-src/maps/README.md)。源 PNG 原样保留，导出器只编码与记录采样区；九张重解码 RGBA 均逐像素相同、各 <2 MiB。
- 墙体读同一完整模型的顶/身区域，以最近邻校准为 80×80 顶部和 80×96 墙身；世界宽 8、墙身投影高 9.6，严格保持下部高宽比 1.2。墙块在物理轮廓外按 y/x 叠放；所有方向不旋转正面。
- 四向门全部重绘，各主题均有开/锁。门占六个模块：横门 48×17.6、竖门 8×48。既有 port 中心落在网格线，采用偶数跨度可保持中心不动且两端均为整块边界。共享 `mapDoorRect(port)` 同时决定墙层切空与门对象位置，避免两套尺寸/偏移漂移；纵门整体随墙顶向上投影 9.6。横门亮顶高 8、暗墙身高 9.6；竖门上下端帽各 8×8，中段 8×32。启动时归一化到两个缓存图集，最近邻采样，实心材质底色保证矩形无透明漏缝；切空范围恰好六块完整墙，不垫墙。门触发、传送入口、碰撞、开锁时机不变。主城门使用同一规则。
- 地板采用 ground-v4，取消镜像、整层压暗与内缘暗线。32 单位周期内以 12 个不等尺寸砖面和材质色细缝铺设，砖块跨边平移续绘；采样只取原图砖面内部，避免源图边框叠加。障碍下连续铺同一层地面，不用矩形深色底板；新不规则障碍的透明角和接触阴影显示其下地板。
- 四主题独立嵌地边框按八块九宫格边/角绘制，内口严格沿机关 footprint、厚 3 单位向外扩，中心不覆盖地面；宽窄/长短机关共用，直边和转角连续。水流/海草重复 32、地刺 16。机关状态、桶和地雷判定尺寸、伤害范围、计时仍读原 sim。
- 宝箱/出口、主城祭台、金币/生命/能量补给、落石/奶池/毒雾同步用新素材。补给复用已有掉落图片池；危险区使用固定 24 槽图片池，不逐帧 new/destroy。毒雾新贴图使用专用透明度 0.85，保留原圆形边界和冒泡，避免沿用纯色填充 0.22 后在深色地板难以辨认。普通怪/Boss 的预警形式、伤害与判定不变。关闭宝箱、灯具、苔藓、珊瑚、碎屑新帧作为素材储备，未引入新玩法或额外摆件。
- 房间仍是一张 2624×1856 CanvasTexture、同尺寸离屏墙层和 16 个障碍 TileSprite，只在建房烘焙。地板图案缓存从约 16 MiB 降至约 4 MiB；新增门缓存约 4.8 MiB。六张被替代的模块 WebP 删除；旧 LegacyRoomArt 审计资源保留但生产加载器不再预加载旧地图/门/祭台图。整套模块缺失时仍按真实轮廓回退灰盒。
- 部署后以本批画面替换线上灰盒。相机、角色大小、房间拓扑、物理轮廓与面积不变。当前仍只支持 8 单位网格的轴对齐轮廓；更多房型/45° 墙留 #115，斜墙不设门。每主题 200 个测试布局仅验证组合复用。

新实景、全量资源审计和本地验证见 [v3 记录](../testing/unified-map-art.md)。负责人要求先不复审，故新图尚未获画面认可，PR 保持 Draft；自动化不能代替负责人真机确认。

## 行为与存档

房间扩大使出生候选、随机采样接受率、外墙碰撞位置和走位距离发生变化，不能承诺新旧版本相同 seed 的出生坐标或整场 RNG 相同。中心、旧障碍和 Boss 房尺寸保持；同版本恢复必须精确一致。更新指纹覆盖 src/public，本次上线仍按 #132 结束旧冒险并返回菜单，保全天赋点、已购天赋及局外档案，无跨版本战斗迁移。

沿用 #132 已被武器负责人接受的外墙行为：弹跳弹撞墙消耗反弹次数、回旋镖折返、光束止于墙。此次前三层外墙位置变远，会相应改变撞墙/折返距离与光束可达长度；没有修改 Arsenal/AI 代码或数值，但不能写成武器行为完全不变。负责人试玩仍需留意外墙手感。初版证据见 [历史记录](../testing/modular-map-art.md)，v17 墙体修订见 [历史 v2 记录](../testing/wall-art-v2.md)，本轮全资源统一见上述 v3 记录。
