# 0011. 固定槽位掉落与房间刷怪数据

- 状态：集成分支试行，待负责人合并 main 批准
- 提出者：GPT
- 批准：负责人（合并即批准）
- 关联：Issue #31、PR #33；集中评审修订

## 背景

击杀奖励与地面武器需要有界存储，并支持同层回访换回旧枪。

## 决定

新增 loot schema：有界掉落槽位、拾取距离、权重/数量、清房奖励、每层敌人表；noDropChance=0.4 是不掉落概率，weaponReserve=1 为武器预留槽。
LootSystem 使用 loot:${floor} 子流；RoomDirector 从 encounters:${floor} 分别 fork enemy-kinds / enemy-positions。
游戏层只把死亡与清房事件接入规则方法，拾取结果由 sim 决定。
血量/能量满时补给留在原地；金币自动收集，武器靠近后显式交互。
普通物资不可占用武器预留槽，满额拒绝生成，换房清空。武器槽记录 room，只在所在房间可见/可拾取，直到换层统一清空。
拾取新枪时把旧第二槽原地换入地面槽，位置设为玩家脚下；第一槽手枪永远不掉。满池也不需要额外空槽。宝箱生成成功后才 claim。
RoomDirector 必须紧接 bridge 的 WORLD_STEP 消费 spawnCount，出生检测由地图适配层提供。
game 为每个掉落槽位预热一个表现对象，不在死亡回调 new/destroy。

## 备选方案

击杀必掉：负责人否决；每次换房清空武器：无法换回；换枪另分配一槽：满池时会吞枪。

## 后果

保留固定容量与预热表现；普通物资换房清空，武器随房间保留至换层。满额宝箱生成失败时不标记已领取。
