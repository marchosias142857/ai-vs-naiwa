# ADR 0037：新怪物图集 v3 与固定身体锚点

- 状态：实现与本地验证完成，待负责人画面、真机与合并批准。
- 提出者：GPT，负责人指定独立完成 #100。
- 延续：ADR 0023、0030、0033、0036。

## 问题

旧普通怪生成器用帧高和碰撞半径推算 pivot，尾巴、长腿和透明边距会影响身体位置；旧奶怪逐帧包围盒对齐也会受伸拳、弯腰影响。负责人同时要求采用本轮新设计的青蛙形象，进一步减少原生像素与动作帧，撤回此前 v2 旧图精绘方案。

## 决定

1. `ActorView.x/y` 继续表示身体圆心，与 sim、Arcade、导航、接触和攻击判定一致。修正遗留“脚底中心”注释，类型和行为不变。
2. 从新概念和新动作原画建立 `art-src/monsters-v3/` 管线，保留来源、提示词、清单和文件摘要。各怪物固定身体锚点、全动作共用帧尺寸、透明留白和脚底线；不读取半径推算美术 pivot。尾巴、肢体、烟气与透明边距不决定物理圆。
3. 原生图片硬边 alpha 为 0/255，纹理像素为 0.5 世界单位，所有新形象默认朝右。新增可选 `MonsterArt.shadowY` 只控制地面影子；腾空时图片受 `lift` 影响，影子留地。旧资源未配置时仍使用 radius。镜像 pivot 与像素对齐只改变图片，物理代理不读取帧大小或图像缩放。
4. 保留全部 `ENEMIES.radius` 与玩法数值：共 3、4、5、6、8、9、14 七种半径，玩家不增加新半径，导航缓存容量 8 足够。对象池获取/读档继续完整设置圆、offset、前帧位置与 enable。没有寻路容量、物理 offset、速度、生命或伤害调整。
5. 普通怪每种 24 个关键帧：待机/移动各 4，蓄力/攻击/收招/受击各 2，特殊/死亡各 4。奶怪增加旋身与大笑各 4。蓄力、攻击、腾空、收招播到末帧保持，循环动作仍循环。受击用现有 `hurtAt` 短暂覆盖普通动作，不改变 sim 状态、不重置步态时钟、不遮住出招，也不在冻结时播放。
6. 普通死亡保留 0.45 秒，奶怪保留 1.4 秒闪抖、0.8 秒大笑、0.8 秒消散，总时长 3 秒。采用实际绘制的大笑和倒地帧，不用整张图片拉伸代替动作。
7. 资源 URL 升为 `monsters-v3.png` / `naiguai-v3.png`，纹理 key、怪物 ID、帧查询接口保持稳定。图鉴复用注册表；中英文名称与外观说明同步新形象。退休运行目录中的 v1/v2 文件，Workbox 从当前构建生成缓存，用户确认更新后换整套资源。
8. 存档格式、物理数据指纹不变；跨构建存档沿用现有兼容兜底，不新增存储键、不改 FxBudget、锁步或带种子随机。红色危险预警与攻击判定保留，#101 尚未启动。

## 验证与取舍

真实 PNG 解码覆盖 16 种、392 个注册帧的非空、透明边界、硬像素 alpha 和待机/移动姿态差异。真实 Arcade 测试覆盖全部动作/兜底、左右镜像、腾空、固定影子、受击恢复、冻结、一次动作末帧保持、圆周探针、墙面/世界角落/圆桶、存档恢复、死亡停用，以及 Boss→蝌蚪等 34 次槽位获取。

少帧像素动画仍需负责人确认节奏、身体主体与命中范围是否合适；自动化不能证明主观流畅度或手机 FPS。新图集仍为两张纹理，解码内存较 main 增加约 1.54 MiB，详见 [#100 验证记录](../testing/monster-art-v3.md)。
