# ADR 0034：边缘居中镜头与房间外纯黑背景

- 状态：待负责人合并批准。
- 背景：负责人要求人物移动到房间边界时仍保持在画面中央，视野超出房间的部分显示纯黑背景。

## 决定

- 主城与正式地牢共用 `RoomCamera`，移除房间加外沿的滚动限制及跟随插值。每个渲染帧以玩家身体中心减去半个可见范围设置滚动；保留最终渲染像素对齐，因此人物在中心的误差最多为半个渲染像素。换房、换层、恢复与窗口尺寸变化使用相同计算，不保留旧位置。
- 删除铺满视口的墙砖 TileSprite，改用世界相机不透明的 `#000000` 清屏色。地面、实体边墙、门与其他房间美术维持现有范围；超出房间的空白由纯黑底色自然填充，不创建新的背景对象或纹理。
- 保留现有 1080p 渲染、自适应横屏宽度和桌面/手机相机倍率。`ROOM_VIEW.padding` 只用于既有超宽屏倍率计算，不再限制滚动。UI 仍覆盖在整个画布上，坐标不跟随世界滚动；屏外方向标记、鼠标世界坐标换算及双摇杆继续使用原接线。
- 本决定替代 ADR 0028 的平滑跟随/边界限制及 ADR 0029 的房间外墙砖背景，不改变物理房间、门口判定、sim、随机流、存档格式和人物动作。灰盒与压力场景保留原有镜头。

## 取舍与验证

靠墙时可见房间面积减少，房间外黑色区域增大；这是负责人要求的表现。镜头直接跟随，不再产生移动时的平滑滞后。屏外敌人与门的提示保持可用，黑色背景不影响碰撞或攻击判定。

验证覆盖真实移动至四个墙角、移动途中居中误差、门口及换房、窗口尺寸变化、鼠标瞄准、触控输入、主城与续玩；截图检查房间外像素为纯黑。记录见 [居中镜头验收](../testing/centered-room-camera.md)。
