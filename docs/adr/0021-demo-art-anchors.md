# ADR 0021：demo 图集、逐帧持握点与固定枪口

- 状态：待负责人合并批准
- 背景：负责人授权 GPT 独立完成 demo，美术可以直接制作。大肥鱼动作参考已提供，武器必须独立绘制并自带握把上的手。

## 决定

- 五张真实 PNG：大肥鱼、十二件武器、七种敌人、环境物件及标题背景。源图不在运行时裁切复制；Texture 的命名帧共用图集。
- `data/art.ts` 配合 `data/schema/art.ts` 存储帧矩形、动画时长、逐帧 pivot / grip、武器握把与相对枪口点、缩放和朝上遮挡阈值。坐标均明确为源图像素；`standardGrip` 是相对物理圆心的游戏像素。
- 当前持握点由 GPT 对照参考图标注，为可调整初值。运行帧持握点仅影响表现，sim 使用固定标准点和武器偏移，维持 ADR 0004 的确定性。
- 接入表现时镜像持握点 x，绕握把转动武器；左侧瞄准上下翻转局部武器坐标以保持枪身朝上，朝上 60° 锥内画在身体后方。翻面不改变 ADR 0020 朝向。
- 本 PR 增加资源、数据与加载；身体圆心和 sim 枪口接线在独立后续 PR 实现并验证。

## 替代方案

- 每帧单独 PNG：请求与资源管理更零散，放弃。
- 用动画持握点生成子弹：战斗结果会依赖渲染帧和动画时钟，放弃。
- 继续使用灰盒：本阶段负责人已明确要求可玩的正式感 demo，不适用。

## 后果

新增约 6.6 MiB 图片，均低于单文件 2 MiB 的离线缓存预算。敌人图集与角色/武器图集分开便于迭代；需在组合场景检查透明边缘、手机辨识度及 draw call。角色参考保留在 art-src，不打入离线包；来源与生成提示记录在 art-src/demo/README.md。不使用现有作品角色或第三方商业素材。
