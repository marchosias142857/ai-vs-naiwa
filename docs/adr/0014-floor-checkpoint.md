# 0014. 楼层入口检查点

- 状态：集成分支试行，待负责人合并 main 批准
- 提出者：GPT
- 批准：负责人（合并即批准）
- 关联：Issue #31、PR #33；集中评审修订

## 背景

需要基本续玩，同时明确楼层检查点与完整局面存档的区别。

## 决定

浏览器 localStorage 保存 version=1 的楼层入口状态。继续从该层入口开始，不恢复中途的弹丸、怪物、技能计时或房间进度；菜单明确说明。新局与每次换层保存，死亡/通关清除。存储失败不能阻止开局。

数据带 schema；纯 sim 的 parseCheckpoint 在运行时验证不可信 JSON，不打包 zod。保留种子、升级序列、双武器、生命/护甲/能量/金币与累计成绩。未知版本、非法数字和未知 ID 拒绝恢复。

CombatWorld 新增 restorePlayer：只能在 time=0、玩家活着时恢复资源；先重放升级以得到上限，再夹取资源值。禁止恢复 NaN/Infinity/负数。DungeonRun 支持合法起始楼层，依旧由独立 map:floor 随机流生成同一地图。

升级、掉落、刷怪分别按 upgrades:${floor}、loot:${floor}、encounters:${floor} 从不消耗的根流派生，换层重置。因此这三条流在同种子的同一楼层入口，继续与不中断推进一致；地图/布局也按楼层派生。
这仍不是逐帧回放：房内状态、战斗散布/暴击流、技能计时与飞行弹丸不保存。完整状态存档 v2 在 #33 合并后单独立项，Claude 定义 sim 保存/恢复 ADR，GPT 接存储和 pagehide/后台保存。

## 备选方案

立即保存全部房内状态：本轮未定义完整契约；只有种子：会丢掉升级与资源。完整存档 v2 留给 Claude 单独 ADR。

## 后果

现有 v1 key/version 保持，secondary 可为 null；旧字符串检查点仍可读，旧 secondary=pistol_basic 归一为空。退出后的房内进度仍不保存。

当前入口检查点由 GameScene.update 首次观察到楼层变化时写入，可能已推进少量物理时间；pagehide 没有新的房内快照可写，故本版不增加保存动作。v2 在原始 pagehide/后台回调同步保存完整状态时再接入。
