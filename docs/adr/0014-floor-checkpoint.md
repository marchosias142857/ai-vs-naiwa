# ADR 0014：楼层入口检查点

状态：demo 临时授权实现，随集成 PR 由负责人批准。

浏览器 localStorage 保存 version=1 的楼层入口状态。继续从该层入口开始，不恢复中途的弹丸、怪物、技能计时或房间进度；菜单明确说明。新局与每次换层保存，死亡/通关清除。存储失败不能阻止开局。

数据带 schema；纯 sim 的 parseCheckpoint 在运行时验证不可信 JSON，不打包 zod。保留种子、升级序列、双武器、生命/护甲/能量/金币与累计成绩。旧版本、非法数字和未知 ID 拒绝恢复。

CombatWorld 新增 restorePlayer：只能在 time=0、玩家活着时恢复资源；先重放升级以得到上限，再夹取资源值。禁止恢复 NaN/Infinity/负数。DungeonRun 支持合法起始楼层，依旧由独立 map:floor 随机流生成同一地图。

这是检查点恢复，不是精确回放：战斗、掉落与刷怪随机流从检查点重新初始化；同一检查点可复现，但不承诺接续退出前的逐帧随机序列。将来如需完整回放，另行版本化全部随机流与房内状态。
