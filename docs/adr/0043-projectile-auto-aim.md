# ADR 0043：攻击轮盘零死区与全平台弹体自瞄

状态：负责人在 #140 合并后授权一起完成 #116/#129；GPT 起草并实现，待 Claude 武器机制复审与负责人试玩合并。

## 输入契约

攻击触点按下当次采样即 `fire=true`，不再等待 120 ms。相对攻击轮盘固定圆心的任意可表示非零偏移立即归一化为 `InputFrame.aim`，不设正数阈值；精确回中时为 null，但按住仍攻击。取消、释放、后台、暂停与尺寸变更沿用现有清理和多指所有权，左摇杆及硬件手柄死区不改。

`InputFrame.aim` 仍是原始手动方向，输入层不知道武器类型。鼠标、触屏和手柄共用 sim 的选敌规则，不能在手机表现层覆写弹道。此决定替代 ADR 0020 的取消自瞄规则及 ADR 0025/0028/0029 中的攻击死区、首发等待规则，其他约定继续有效。

## 武器分类与选敌

- 数据 `attack` 为 `projectile` 或 `shot` 的武器自瞄，当前 20 款，包含回旋镖及近距离环绕弹体；按实际攻击类型判断，不按设备或武器 ID 建白名单。
- `beam`、`melee` 保持手动，目前是灯笼激光、弯刀、锚锤、旗鱼枪与鲨鱼刀五款。
- 每个固定物理步先计算原手动/移动朝向，随后在按住攻击、尚有 burst 或已蓄力待释放时选敌。武器切换发生在选敌前。蓄力释放步同样按攻击处理身体朝向，避免出手时身体瞬间转回移动方向；未攻击时保持原朝向规则。
- 候选必须为异队、active 阶段、非地下/出土隐藏态，身体中心距离大于零且不超过该武器 `range`。距离相同取最小实体 ID，回收池顺序不决定平手。
- 使用既有 `CombatWorld.los`：生产地图的 LOS 几何查询，加落地石块、未破桶遮挡。近敌不可见时继续寻找更远的有效目标。无候选则保留本步原方向：手动优先；触屏无手动方向用最后移动方向，桌面/手柄无输入保留原有规则。
- 瞄准目标当前身体中心，不预测移动；最终枪口到目标的方向作为弹型基准轴，不改变发射点、散布、碰撞半径或弹型。`range` 作为选敌距离；不缩短弹体原寿命，也不延长弹体原行程。

采用每步重新选择最近目标，没有锁定对象、保持时间或换目标计时器。这样死亡、隐身、遮挡、出射程能在下个攻击步立即生效，不增加存档状态；距离交叉时可能换敌，属于本次明确的手感选择，待负责人试玩。旧 `AutoAim` 类的 0.25 秒锁定算法仍无生产调用，不能将两套规则混为一谈。

## #142 复审增量：实际枪口到目标

Claude review 5704997926 指出身体中心方向与实际枪口的平行偏移会让正下方半径 3 的目标必空。修复将本步目标通过 `pullTrigger` 传给 `fire`：先按既有 `placeMuzzle` 得到最终枪口（包括近墙回退），再取 `atan2(target − muzzle)` 作为 `FireContext.aim`，`weapon:fired.angle` 同步记录该弹型基准轴。身体和持械仍取中心朝目标的姿态，枪口位置/左右镜像不变；实际弹道与枪身朝向允许有收敛夹角，近距离更明显，交负责人试玩确认。

没有采用反复覆写 `actor.facing` 的迭代：`playerMuzzle` 的持握侧由 `cos(facing)` 决定，向下的左右镜像接缝是不连续的；正下方手枪两次迭代仍会反复换侧，不能保证射线穿过目标。固定枪口后直接求方向，避免这个环。目标的中心距离小于或等于枪口的中心距离时保留中心方向，避免朝身后补偿；中心重合目标仍不入选。

散布、扇形、环形和双管均在修正轴上执行原弹型，因此不承诺每颗散布/偏轴弹丸都穿过圆心。单测检查全部 20 款的实际发射基准轴，并额外检查零散布狙击的真实 `BulletSpawn`；真实 Arcade 另检查手枪和狙击命中正下方小怪。目标只是本步局部引用，不新增锁定状态、随机调用、存档字段或帧内分配。LOS 仍从身体中心检查；枪口到目标被墙角遮挡的非阻塞建议留待后续决定。

## 不变项与验证

按下即攻击指立即交给原攻击机制，不绕过冷却、耗能或蓄力：弓仍按住蓄力、松手发射，burst 松手后剩余子弹仍按原节奏发出。伤害、射速、能耗、散布、弹体碰撞、AI、房间、玩法随机与存档结构不变。选敌只读实体和视线，无随机调用、无帧内对象分配。

本次没有新增 `InputFrame` 字段、存档字段或依赖。单测覆盖全部 25 款 × 三种输入来源、无目标/遮挡/隐藏/预警/死亡/范围/平手、连射与蓄力释放、切枪、同版本恢复；浏览器以真实 DOM/Phaser 手柄输入经过 DemoSession、CombatBridge、Arcade，核对实际攻击。结果与限制见 [验证记录](../testing/player-auto-aim.md)。
