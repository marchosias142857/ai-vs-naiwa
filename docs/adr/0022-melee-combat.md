# ADR 0022：近战攻击、事件与挥动存档

- 状态：待负责人合并批准
- 依据：负责人要求武器分弹幕/近战，sim 按 WORLD_STEP 判定，挥动中状态进入存档。

## 决定

- 武器 schema 增加 attack（projectile / melee）和 melee 参数：范围、扇形总角度、挥动时长、冷却。新增潮汐弯刀、船锚重锤；共用既有拾取、第二槽与输入流程。
- 每个固定步计算身体圆与闭扇形的相交，并检查地图视线；只打活动敌人，每次挥动对每个实体编号最多命中一次。挥动方向在开始时锁定，攻击区域跟随身体中心，瞄准仍遵守 ADR 0020。
- 近战复用单个状态记录，不借用子弹池；weapon:swung 供挥动音效/表现订阅，melee:hit 在伤害及死亡通知之后发出。伤害、暴击、击退由 sim 结算。
- 换武器取消挥动，保留原冷却；玩家死亡立即取消。攻速升级等比例缩短挥动和冷却。
- CombatWorldState 保存 active、weaponId、angle、remaining、duration、damage 和 hitIds。恢复静默写入，不重播事件。共享字段规则同时生成轻量校验和 zod schema；校验目标编号、攻击类型和时间/武器关系。旧构建存档按 ADR 0019 走独立入口兜底。

## 验证

覆盖范围、扇形边界、墙体、冷却、单次命中、换枪、零子弹池，以及挥动中 JSON 往返后 180 步的完整状态与事件逐项一致。新增数值均为可调整 demo 初值。
