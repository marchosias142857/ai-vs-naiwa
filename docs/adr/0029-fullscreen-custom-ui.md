# ADR 0029：全屏地图与可保存的覆盖式 UI

状态：待负责人合并批准。

后续替代：ADR 0034 将房间外墙砖背景改为纯黑，并要求人物在边缘也居中；本 ADR 的全画布世界视口及覆盖式 UI 规则保留。

## 背景与决定

负责人在 PR #91 后明确要求按参考图恢复全屏地图，摇杆与动作按钮覆盖在画面中，并能在设置内修改生命、护甲、能量及操作 UI 后保存。本决定替代 ADR 0028 的侧栏和顶部/底部预留区域，保留跟随、像素对齐和自适应安全区画布。倍率以 1.5 倍为下限，超宽手机按房间宽度适当增加，减少墙外区域占屏。

- 世界相机覆盖完整画布；房间外以现有墙砖纹理补足环境背景，不再用黑色 UI 侧栏裁掉世界画面。房间碰撞和地图尺寸不变。
- 生命、护甲、能量各自一行，默认位于左上；左右摇杆与三个圆形动作按钮半透明叠在地图上，小地图继续可收起。
- 八个 UI 元素可独立拖动、缩放（80%–150%）、调透明度（25%–100%）；默认位置按边缘留距，定制位置按安全画布中心比例保存。最终位置限制在画布内，避免旋转或小屏令按钮丢失。
- 正式主城/地牢使用固定移动摇杆，使绘制基座与保存的命中位置一致；灰盒仍使用原浮动摇杆。射击死区随尺寸同比例改变，120 ms 原地按住首发等待、多指所有权、有符号触点规则保持。
- 编辑器从标题设置和暂停菜单进入。使用独立草稿，保存成功才更新运行时 UI；取消不写存储，恢复默认后仍需保存。操作区互相重叠或覆盖固定地图/暂停入口时提示调整；存储失败保留草稿并显示错误。
- 使用独立 `avn.ui-layout.v1` 存储，与旧音效/语言设置及冒险存档互不覆盖。损坏或缺失值回落默认，异常数值限幅；不新增依赖。
- 编辑时隔离游戏键盘、触控与手柄输入；局内始终保持原暂停状态，关闭编辑器回到暂停菜单。画布尺寸变化时刷新控件绘制与触控命中，刷新/离线重开重新加载已保存布局。

## 取舍

控件按用户选择覆盖在场景内，会遮住其所在位置的少量内容；通过透明度和拖动避让。极端宽高比下定制控件虽然会限制在画布中，仍可能靠近或重叠，编辑器保存时检查当前尺寸的重叠，用户可恢复默认。真机舒适度、持续帧率及 WebKit 兼容性需另行验收。

用户参考图仅用于理解画面布局；imagegen 输出为概念示意，不当作实际游戏截图或运行素材。交付截图来自实际生产构建。
