# ADR 0017：实体规则记录预热

状态：demo 临时授权实现，待集中评审。

新增 POOL_SIZES.actors=31 与 CombatWorldOptions.maxActors（默认 31）。Phaser 角色与 sim 的 Actor/base/knock/brain 记录均预热；刷怪重置已有字段，死亡回收后不会随房间数积累记录。超出容量明确抛错，生成导演须遵守同时存在上限。

removeActor 立即移除编号和视图列表。战斗方法/生成方法的同步调用栈内，把记录放入退休队列；最外层调用结束后才回到空闲池。场景死亡表现结束后的普通回收立即进入空闲池。这样 entity:died 的同步监听器移除实体后，同一次命中剩余的 bullet:hit 仍读取原目标编号，不会拿到复用后的新实体。同步事件补怪需要空闲余量，不能抢用仍在外层调用栈使用中的记录。

同时修复输出队列满时先弹出子弹空闲记录导致的容量流失：先检查当步 BulletSpawn 容量，再取得子弹记录。增加同步回收弹丸与多发射者回归。
