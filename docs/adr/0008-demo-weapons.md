# 0008. demo 武器与弹道装备

- 状态：集成分支试行，待负责人合并 main 批准
- 提出者：GPT
- 批准：负责人（合并即批准）
- 关联：Issue #31、PR #33；集中评审修订

## 背景

多种武器需要共享无分配的弹道生成接口。

## 决定

api 新增只读 weaponId: WeaponId 与 equipWeapon；装备不清空已有冷却，取消上一把武器的待发连射。
schema 新增 radial / twin 弹道枚举与可选 burstInterval。十把武器使用五类已实现弹道：
single 随机散布、spread 均匀扇形、radial 环形、twin 平行多枪口、burst 按物理步计时连射。
FireContext 增加可选 pelletCount，连射复用同一上下文而不创建临时武器数据。
新数据均为 demo 初值，沿用占位纹理，正式枪械视觉待画面方案。
能量消费与双武器携带在后续资源 PR 接入；本 PR 只增加弹道与切换接口。

## 备选方案

每把武器新建子弹数组/闭包：增加战斗帧分配；各自实现冷却：容易切枪绕过射速。

## 后果

弹道复用上下文；切枪保留冷却，数据条目可独立扩展。
