# ADR 0031：特殊弹体、光束、蓄力、预热与突进近战

- 状态：提议
- 提出者：Claude
- 批准：负责人（合并即批准）
- 关联：ADR 0008（弹道）、ADR 0019（存档）、ADR 0022（近战）、ADR 0030（怪物招式）

## 背景

负责人 2026-10-24 要求参考泰拉瑞亚、元气骑士、贪婪地牢与类幸存者游戏添加武器。

现有 12 把武器只有两种攻击方式：Arcade 子弹（直线飞行，命中即结算）和近战扇形。参考游戏里有代表性的武器大多需要更多东西：

- 弹体会转弯（追踪、回旋、环绕、反弹）；
- 命中后有后续效果（爆炸、分裂、连锁闪电、冰冻）；
- 开火方式不同（按住蓄力、越打越快、持续光束）；
- 近战带位移（长枪突刺、太刀冲刺斩）。

Arcade 子弹由表现层的物理体移动，sim 不知道它们的位置，也没法改它们的速度，所以这些效果做不进现有子弹。

## 决定

### 1. 特殊弹体 `shots`（sim）

- 新增 `src/sim/weapons/Arsenal.ts`。它管理固定槽位的特殊弹体（数量见 `BALANCE.shotCapacity`），每个物理步由 sim 自己移动弹体并结算碰撞：
  - 打墙：用地图视线判断这一步的线段，落地的石块也算墙；
  - 打实体：线段扫过目标圆就算命中，不会因为飞得快而穿过去。
- 弹体的运动方式 `shot.motion`：

| 值          | 行为                                                        | 参考                         |
| ----------- | ----------------------------------------------------------- | ---------------------------- |
| `straight`  | 直线                                                        | —                            |
| `homing`    | 每隔一段时间找 `seek` 范围内最近的敌人，按 `turn` 转向它    | 泰拉瑞亚魔法飞弹、幸存者魔杖 |
| `boomerang` | 飞 `out` 秒（或撞墙）后转身飞回发射者，回程穿墙，接住即消失 | 泰拉瑞亚回旋镖、幸存者十字架 |
| `orbit`     | 绕发射者转圈，同一发射者的环绕弹按槽位顺序均分角度          | 幸存者国王圣经               |
| `bounce`    | 撞墙按墙面反弹，次数用完后消失                              | 泰拉瑞亚水箭                 |

- 弹体结束（命中不再穿透、撞墙、寿命到）时的效果：
  - `shot.burst`：范围爆炸，复用 ADR 0030 的 `explodeAt`；
  - `shot.split`：向四周放出直线小弹。
- 命中时的效果：
  - `chain`：连锁闪电，从命中目标跳到最近的、没被这串闪电打过的敌人，伤害逐跳衰减，每一跳发 `weapon:chained`；
  - `chill`：冰冻层数。每层让怪物移动减速，叠满 `stacks` 层后冻结 `freeze` 秒；冻结的怪物不行动、不移动，冻结结束后层数清零。
- `shot.max` 限制同一发射者同一把武器同时存在的弹体数，到上限时开火不生成、也不扣能量（回旋镖必须接住才能再扔）。
- `shot.rehit`：同一弹体隔多少秒可以再次命中同一目标；不填则每个目标只命中一次。回旋镖转身时清空命中记录。
- 命中发 `bullet:hit`，表现层复用现有的命中火花与音效。

### 2. 武器字段（`WeaponDef`，全部可选，不影响现有武器）

- `attack` 新增 `shot` 与 `beam`。
  - `shot` 必须有 `shot` 参数，弹道 `pattern` 照常决定出几发、朝哪些方向，只是生成的是特殊弹体而不是 Arcade 子弹；
  - `beam` 必须有 `beam` 参数，弹道为 `beam`。
- `beam`：按住开火时，从枪口沿瞄准方向射出光束，直到碰到墙。每 `tick` 秒对光束经过的全部敌人造成一次 `damage`；每 `costEvery` 秒扣一次 `energyCost`。
- `charge`：按住蓄力，松开才发射，蓄力最多 `time` 秒。
  - 伤害、弹速按蓄力比例从 `minScale` 插值到 `maxScale`；
  - 蓄满时额外穿透 `fullPierce` 个目标；
  - 不到 `minTime` 秒就松开，打出最弱的一发。
- `spinup`：按住时射速在 `time` 秒内从 `startRate` 升到 `fireRate`，开火期间移动速度乘 `moveScale`；松开后按 `cooldown` 的速度降回来。
- `melee.lunge`：挥动期间沿挥动方向突进的距离（像素），会覆盖移动输入；挥动结束时速度收回到正常移动上限，不会滑出很远。`melee.dashInvulnerable` 为 true 时突进期间无敌。
- `EnemyDef.freezeImmune`：冰冻叠满时不冻结，只保持最大减速。奶怪设为 true。
- 光束只在打开的那一步发 `weapon:fired`（枪口火光与音效），之后每次伤害发 `bullet:hit`。

### 4. 共享契约

- `CombatWorld` 新增只读：
  - `shots`：全部弹体槽位（含未激活的）；
  - `beam`：当前光束的起点、角度、长度与宽度；
  - `charge`：当前蓄力比例 0～1。
- `ShotView` 给表现层画弹体：位置、朝向、自转角、半径和来源武器。
- `ActorView` 新增 `chill`（0～1，当前减速比例）与 `frozen`（是否冻结）。
- 事件新增 `weapon:chained`：`{ team, x1, y1, x2, y2 }`，每跳一次发一次，只给特效用。
- `clearHazards()` 同时清掉全部弹体与光束。
- 新增随机流 `fork('shot')`，用于弹体的随机偏转（目前只有分裂小弹的起始角），存档为 `rng.shot`。
- `BALANCE.shotCapacity`：弹体槽位数。

### 5. 存档（ADR 0019）

`CombatWorldState` 新增：

- `shots`：只保存激活的弹体，包含**槽位下标** `slot`、位置、速度、阶段计时、剩余穿透和反弹次数、命中记录；
- `beam`：是否开着、下一次伤害与扣能量的倒计时；
- `player.charge`、`player.spin`；
- `melee.lunge`；
- 每个实体的 `status`（冰冻层数、每层减速、清零倒计时、冻结剩余秒数），`chill`、`frozen` 读档时由它算出；
- `rng.shot`。

**恢复到原槽位**：弹体按槽位顺序移动，结束时分裂出的小弹占用第一个空槽，所以槽位本身影响结果。

- 之前读档会把存活弹体从槽位 0 起连续排列。GPT 复现过：火箭到期空出槽位 0 后存档，读档后海胆刺多走了一步。
- 现在弹体回到原槽位。ADR 0030 的区域（`zones`）与石块（`rocks`）有同样的问题（新区域占第一个空槽、按槽位遍历），一并加上 `slot`，同样恢复到原槽位。

`parseSnapshot` 交叉检查：

- 弹体编号与发射者编号不能超前，来源必须是带 `shot` 参数的武器，命中记录不能超前；
- 区域、石块、弹体各自的槽位不能重复，字段规则限制槽位小于对应容量。

### 6. 表现（game）

- 新武器图集 `public/assets/demo/arsenal-v1.png`（512×103，约 9 KB），由 `art-src/arsenal/build_arsenal.py` 生成，帧数据在 `src/data/arsenalArt.ts`。
  - 武器图 1 个图集像素 = 0.25 游戏像素，长 12～20 游戏像素，与原武器图相当；握把处画大肥鱼的拳头，与原武器图一致。
  - 弹体图按 0.4 显示，和原来 6 像素的子弹差不多大。
- `WeaponArt` 新增可选 `texture`。不填时用原武器图集，新武器指向 `demo_arsenal`；握把、枪口、缩放的含义不变。
- 新增 `src/game/fx/WeaponFx.ts`：负责画弹体、光束、连锁闪电、蓄力圈。被冻住的怪物在 `EnemyArt` 里染成冰蓝色并停住动画。

## 备选方案

- **让 Arcade 子弹支持转向**：每步要把 sim 的速度写回物理体，还要把位置同步回 sim。这会改 CombatBridge、BulletPool 与存档里子弹的含义，影响全部现有武器和敌方弹幕。
- **每种效果单独做一套系统**：回旋镖、环绕、追踪的碰撞与存档代码会重复三份。

## 后果

- 现有 12 把武器、敌方攻击与 Arcade 子弹池的行为不变。
- 特殊弹体只在 sim 里碰撞。弹体数受 `shotCapacity` 限制，超过上限时开火不生成。
- 敌人以后也可以通过同一份字段使用特殊弹体，本 PR 先只给玩家武器用。
