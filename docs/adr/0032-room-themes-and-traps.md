# ADR 0032：楼层主题、房间方案与机关

- 状态：提议
- 提出者：Claude
- 批准：负责人（合并即批准）
- 关联：ADR 0012（房间布局）、ADR 0019（存档）、ADR 0030（怪物招式）、ADR 0031（武器）

## 背景

负责人 2026-10-24 要求：做更多地图素材，让房间表现更多样；房间里加机关，提升交互性。

原来每层的房间画面一模一样，战斗房只有 4 种内墙布局，房间里除了墙没有任何可以互动的东西。

## 决定

### 1. 楼层主题

- `src/data/traps.ts` 的 `ROOM_THEMES` 按层给出主题，最后一项是 Boss 层：

| 层      | 主题               | 机关                   |
| ------- | ------------------ | ---------------------- |
| 第 1 层 | 海底石殿（原画面） | 海草丛、地刺、水流     |
| 第 2 层 | 沉船货舱           | 鱼雷桶、地刺、漏水水流 |
| 第 3 层 | 珊瑚深渊           | 泡泡地雷、水流、地刺   |
| Boss 层 | 奶池神殿           | 不放机关               |

- 新图集 `public/assets/demo/rooms-v1.png`（约 10 KB），由 `art-src/rooms/build_rooms.py` 生成，帧数据在 `src/data/roomArt.ts`。
  - 1 个图集像素 = 0.5 游戏像素：地砖 32 游戏像素、墙砖 16 游戏像素，与原房间网格一致；
  - 地砖、墙砖、障碍块、水流和海草都是无缝贴图。第 1 层继续用原有的 `environment.png`。
- `RoomArt` 从一次性创建的函数改成类，换层时只换贴图与位置，不增删对象。
  - 新主题的内墙由 `RoomArt` 平铺障碍块来画：块按短边铺满一格，细长的墙会变成一排箱子或一串礁石，而不是一张被拉长的图。
  - 这时 `RoomArena` 的墙体只保留碰撞，不显示。第 1 层的内墙画法不变。
  - 新图集没加载成功时，退回原有画面。

### 2. 房间方案

- `ROOM_LAYOUTS` 新增 5 种内墙：中央掩体、上下两道长廊、一圈柱子、两角 L 形墙、散落的箱子。墙体槽位由 8 个增加到 16 个。
- 每个主题有若干「方案」（内墙布局 + 一组机关）。战斗房由种子从本层主题里选一个，原来的 `layout:${floor}:${roomId}` 随机流不变，只是取值范围改成方案数。
- 单元测试检查每个方案里的机关都在房间里、不压内墙、不挡四个门口的入场点。

### 3. 机关（sim）

- 新增 `src/sim/room/Traps.ts`，固定槽位，数量见 `BALANCE.trapCapacity`，效果通过 `TrapHost` 交给 CombatWorld 执行。
- 机关不分阵营：玩家可以把怪物引到地刺上、引爆鱼雷桶炸怪；怪物也会踩响地雷，误伤玩家。
- 地刺、水流、海草、地雷只影响站在地上的角色，腾空和钻地的怪物不受影响。

| 机关     | 形状 | 行为                                                                                             |
| -------- | ---- | ------------------------------------------------------------------------------------------------ |
| 地刺     | 矩形 | 收起 → 预警 → 刺出循环，刺出时伤害站在上面的所有角色，每次刺出每人最多一次；`delay` 错开相邻地刺 |
| 水流     | 矩形 | 把区域里的角色往水流方向推，冻住的怪物也会被冲走                                                 |
| 海草丛   | 矩形 | 区域里的角色减速                                                                                 |
| 泡泡地雷 | 圆   | 有角色碰到就点燃，短暂延时后爆炸，伤害范围内所有角色；之后重新布设                               |
| 鱼雷桶   | 圆   | 挡路、挡视线、挡子弹；被子弹、近战、爆炸、特殊弹体打掉耐久后爆炸，可以连锁引爆                   |

- 数值集中在 `TRAP_RULES`。
- 水流推力与海草减速每步重新计算，在 `applyVelocity` 里叠加，不存档；与奶潭、冰冻、加特林减速相乘。

### 4. 共享契约

- `CombatWorld` 新增：
  - `traps`：全部机关槽位；
  - `setTraps(room, traps)`：`room` 是调用方给的房间编号（`floor × 25 + roomId`）。编号与当前相同时什么都不做，存档恢复后重建房间不会重置机关计时；换房时全部重新开始。机关不随 `clearHazards()` 清除，因为换房的顺序是先摆新房间、再传送；
  - `hitTrap(bulletId, index, x, y)`：Arcade 子弹打中鱼雷桶。
- `TrapView`、`TrapLayoutInput`、`TrapPhase`。
- `combat:exploded` 的 `team` 改为 `Team | null`，null 表示机关爆炸、伤害范围内所有角色。目前只有 HazardLayer 订阅，它不看阵营。
- `MeleeState.traps`：本次挥动已经砍过的机关槽位位掩码，所以 `trapCapacity` 不能超过 30。
- ADR 0031 的 `ArsenalHost.wall` 多一个 `damage` 参数：特殊弹体撞到鱼雷桶时，按弹体伤害扣耐久。

### 5. 存档（ADR 0019）

- `CombatWorldState` 新增 `trapRoom`、`traps`（形状、阶段、计时、耐久、本次刺出已伤过的实体），以及 `melee.traps`。
- `parseSnapshot` 交叉检查：形状与种类匹配、阶段属于该种类、耐久不超过上限、只有地刺有命中记录、`melee.traps` 不超出机关数。

### 6. 表现（game）

- 新增 `src/game/fx/TrapLayer.ts`：
  - 地刺、水流、海草用平铺贴图：地刺预警时闪烁，水流朝方向滚动，海草左右摆；
  - 地雷、鱼雷桶用单张贴图：地雷点燃时闪红；鱼雷桶耐久过半出现裂纹，爆掉后留下碎片；
  - 立着的鱼雷桶开启静态碰撞体，挡人、挡子弹；子弹打中时调用 `hitTrap`；桶爆掉后让导航网格重新计算。
- `RoomArena.isFree` 把立着的鱼雷桶也算作障碍：刷怪不会刷进桶里，导航会绕开它。
- 冻住的怪物也会被水流冲走（ADR 0031 × 0032）。

## 备选方案

- **机关只做表现、由 game 层判定**：伤害和推力会脱离锁步与存档，同一种子跑出来的结果不一致。
- **用 `room` 以外的方式判断「同一房间」**（比较摆放内容）：两个相邻房间如果选中同一个方案，会把上一个房间打爆的桶带过来。

## 后果

- 同一种子下，战斗房的内墙与刷怪位置会和以前不同（方案选择范围变了），依赖固定种子房间布局的测试可能需要更新。
- 机关会伤到玩家，测试与试玩时需要留意。`?god=1` 下玩家不受机关伤害。
