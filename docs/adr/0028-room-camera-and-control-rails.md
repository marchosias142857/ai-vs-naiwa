# ADR 0028：房间跟随镜头与独立触控区域

> 更新：攻击轮盘死区/首发等待和弹体选敌规则由 [ADR 0043](0043-projectile-auto-aim.md) 替代；下文保留当时决策，其他输入所有权、布局与身体表现规则继续适用。

状态：待负责人合并批准。

后续替代：ADR 0029 替代独立触控区域；ADR 0034 替代平滑跟随与房间边界限制。下文保留当时的决定。

## 背景

负责人要求先处理 main `6ad14ad` 试玩反馈第 1 项：手机角色太小，整屏房间被 HUD、地图、按钮和轮盘遮挡。

## 决定

- 沿用 ADR 0024 的世界坐标、物理尺度、源贴图和高清渲染。主城及正式地牢使用 6 倍渲染相机，即原画面显示比例的 1.5 倍；UI 相机仍为 4 倍。
- 渲染缓冲高度保持 1080，宽度按安全区内的屏幕比例扩展，最小 1920；宽屏手机原有黑边用于触控布局。标题页回到 1920×1080，灰盒和压力场景沿用原镜头。
- 正式房间预留顶部 56 CSS px、底部 56 CSS px；触屏两侧各 160 CSS px，桌面左侧地图区 96 CSS px。相机裁剪到中间区域，控件不叠在房间上。移动摇杆只能从左栏下半部取得触点，远拖时基座仍限于侧栏；右轮盘的尺寸、方向、120 ms 首发等待及多指规则保留。
- 镜头平滑跟随玩家，以房间加 24 世界像素外沿为边界；换房、换层、尺寸变化时立即定位，避免从旧房间拖移。屏外门口用青色方向标记，锁门时置灰；屏外敌人和生成预警用红色标记。标记只反映位置，不修改敌人激活或攻击。
- 状态信息改为顶部短条；显示当前武器一次，完整双槽名称保留在说明文字中；小地图可收起且展开后仍在侧栏。手机操作提示置于右栏。
- 鼠标继续走正式世界相机逆变换，侧栏点击不射击。UI 的暂停、轮盘、倒计时按实际画布宽度布局；死亡压暗和受击边框按世界视口绘制。
- 延续 ADR 0027：角色同一源边按实际相机 zoom 对齐；镜头滚动也对齐该像素网格，保证移动时和左右翻转时取样一致。

## 兼容性与取舍

不改变 sim、数据 schema、存档版本、随机流、战斗数值或角色/武器素材；旧存档继续由正式校验器恢复。不新增项目依赖，不启动远端 CI。

放大后一次可见范围缩小，尤其在 667×375 等较窄手机上；通过边界跟随和方向标记保持门口与屏外敌人可发现。屏外攻击规则沿用原实现，标记不等于展示完整屏外弹道。宽屏渲染增加横向填充量，仍需真机确认持续帧率、发热与拇指舒适度；本轮浏览器模拟不替代真机验收。后续难度评估应使用新视野。

验收记录见 [手机镜头与 HUD](../testing/mobile-camera.md)。
