# ADR 0023：身体中心、固定枪口与独立动画

- 状态：待负责人合并批准
- 依据：负责人要求命中圆与可见身体一致；遵守 ADR 0004、0020、0021。

## 决定

角色 x/y 与 Arcade 圆心、输入瞄准原点均代表身体中心，移除旧脚底偏移。玩家子弹由 sim 的标准持握点和武器局部枪口计算；左瞄准镜像持握点并翻转局部纵轴，视觉层使用同样的变换。近墙挡住枪口时退回身体出生，禁止跨墙生成子弹。敌人从朝向上的身体圆边缘发射，瞄准目标身体中心。

物理代理保持固定纹理和尺寸，后续动画使用独立图片；动画不能改物理 offset、位置或碰撞半径。瞬时动画持握点只影响画面，画面枪口允许数像素误差。相关固定数据纳入存档指纹，旧构建按 ADR 0019 退回楼层入口。

## 验证

单测覆盖所有武器、四向及斜向固定枪口与近墙回退；更新原脚底偏移断言。真实 Arcade 与存档回归继续执行。CI 保留 test-results 截图及失败追踪，支持本环境无法安装浏览器时检查实际渲染。
