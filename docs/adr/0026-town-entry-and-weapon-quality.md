# ADR 0026：主城入口与武器品质

- 状态：待负责人合并批准
- 背景：负责人要求空大厅与一扇可交互的地牢门，开屏分开主城与续玩，并展示武器内置品质。

## 决定

- `SCENES` 增加 `Hub`：Menu → Hub → 确认进入 Game；Menu → Continue 直接恢复 Game。
- Hub 复用角色、房间图集、CombatBridge 的固定物理步和 InputScene，但只传移动；无敌人、战斗动作、掉落、DungeonRun 或 RunPersistence。大厅只有一扇可交互门。
- Hub 绝不写、清除或恢复冒险存档。确认进门后，由新 Game 按原有持久化流程替换旧存档。取消、暂停退出、后台与刷新均保留原存档。
- 暂停原因增加 `interaction`，独立持有门口对话框的物理暂停；关闭时清空输入。生命周期暂停不释放它。键盘 E、手柄 A、手机门按钮共用确认入口。
- 武器沿用已有必填 `rarity`，不添加重复的 quality 字段。白/绿/蓝/紫/橙/红分级在已有 schema 中定义；十二把武器显式配置品质，品质只作元数据，不改变伤害、能耗或掉落概率。当前没有红色武器。
- 存档 v2 和恢复校验不变。与当前构建一致的存档恢复原房间、位置、资源和弹丸；旧构建存档继续使用原有“从本层入口恢复”兜底，并显示原因。

## 画面与资源

- 开屏左上标题“AI娘大战奶蛙”，左下两个主按钮；设置收纳到展开项。右半为方形对峙插画，保持完整构图。
- 新插画采用版本文件名 `title-confrontation-v1.webp`，内置 imagegen 根据两张负责人参考图生成。无损编码 1254×1254、1,713,198 字节，低于 2 MiB 单文件离线预算；删除旧 `title.png`，Workbox 加入 WebP。
- 不改变角色游戏内动作图集。远端 CI 保持禁用，负责人通过本地验证记录和试玩合并。
