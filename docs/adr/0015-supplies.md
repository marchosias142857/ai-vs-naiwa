# 0015. 楼层补给与武器信息

- 状态：集成分支试行，待负责人合并 main 批准
- 提出者：GPT
- 批准：负责人（合并即批准）
- 关联：Issue #31、PR #33；集中评审修订

## 背景

金币需要可用去处，拾取和升级需要给玩家足够的功能信息。

## 决定

金币可在楼层出口的升级选择界面兑换生命/能量。价格与数量放入 LOOT_RULES 及 schema，不放在 UI。CombatWorld.buySupplies 原子校验余额、死亡与资源缺口，满额时不扣钱；DemoSession 只在出口选择期间转发购买。选择升级后关闭商店并进入下一层。

免费手枪固定保留第一槽，宝箱不再抽取相同手枪。武器拾取前显示伤害、弹丸数与能耗；升级显示实际增量，Boss 显示当前生命。只增加功能信息，正式布局待画面方案。

## 备选方案

在 UI 内扣款回血：违反规则分层；无缺口仍扣款：造成无效消费。

## 后果

购买为 sim 原子操作；货币与补给初值由负责人试玩后调整。
