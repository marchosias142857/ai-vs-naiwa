# 0016. 可选绕墙导航回调

- 状态：集成分支试行，待负责人合并 main 批准
- 提出者：GPT
- 批准：负责人（合并即批准）
- 关联：Issue #31、PR #33；集中评审修订

## 背景

追击敌人会被房间内柱子阻挡，混合体型使单个缓存反复失效。

## 决定

纯追击速度会把敌人卡在灰盒柱子后。CombatWorldOptions 增加可选 navigation(x,y,targetX,targetY,radius,out)，返回 true 时 out 给出下一路点，false 时保留原行为。game 按真实墙体提供碰撞查询，NavigationGrid 算法仍位于纯 sim。

8 px 四邻网格，固定 TypedArray 队列/距离/阻挡数组；查询原地写出，按实体半径分别缓存 blocked 与流场，再按目标格更新 BFS，换房失效。路段按实体半径扩墙检查，不能穿过转角。接触墙面的浮点容差只用于导航，不修改 Arcade 碰撞。

只导航向目标靠近的移动；保持距离的后退、炮台和已锁方向冲锋保持原行为。击退仍在自主速度后叠加。新导航数值位于 data/navigation.ts 并带 schema；执行仍在 sim 的 WORLD_STEP 内。

## 备选方案

单半径缓存：混合怪物每次重建；动态无界 Map：半径种类增长时容量失控；每只怪 A*：重复搜索。

## 后果

固定 radiusCaches=4，每个槽各自缓存 blocked/距离/目标；超出种类轮换复用，换房统一失效。目标格 O(1) 定位，贴墙目标只在换格时找替代。
