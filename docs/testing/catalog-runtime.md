## 独立对照方法

生产和测试都改用目录后，单纯比较当前目录与当前 RoomArena 会失去旧行为基线。为此，从 #128 已提交的 `docs/testing/legacy-catalog/review-5677887656.json` 提取 `tests/fixtures/legacyV1/production-baseline.json`：来源代码 head `81a2a77a0678a1eddafaa41bc3bd036347ec4df2`，记录四种子 104 次选图及全部 18 个可到达模板的实际 Arcade bodies、sim 机关和静态几何。它是旧生产 rebuildRoom/show 的历史实测，不由本次选择器公式重建；不修改旧报告或字节基准。

当前浏览器仍运行真实 DemoSession/RoomArena/CombatWorld/Arcade，读取生产选中的 ID，并逐房比较历史 ID、真实碰撞体、机关和 kind/id/mask。种子为 0、42、12345、4294967295；每种子四层共 26 房。fixture 直接枚举 roomId，仅这部分不声称经过真实走门/刷怪；真实走门/三层通关/Boss 和实际 RoomDirector root 单测分别覆盖其路径。同构建完整会话与入口会话各恢复 32 次，四向 teleport、换层、存取档与 root 不变量均保留。
