# 怪物 AI 接入房间几何（ADR 0039「已确认的 AI 接入规则」）

- 实施：Claude，2026-10-27；分支 `claude/114-ai-geometry`，基线 main `a6a8d2d`（#124 已合并）。
- 范围：只改怪物 AI 及其在 `CombatWorld` 里的调用点。几何查询、地图物理和导航归 GPT（#124、#125）。

## 接口

`CombatWorldOptions.geometry?: () => GeometryQueries | null`。这是 ADR 0039 提议 2 里写的「通过 AiHost 或等价的 sim 契约转发」的具体形式，`AiHost` 也新增了同名的 `geometry()` 转发。

- AI 每次决策时调用一次，取当前视图，不缓存。生产环境的提供者先同步动态桶和落石，再返回结果。
- **不传或返回 null 时，所有调用点保持原来的矩形规则，逐字节不变。** 本 PR 合并后，正式游戏的行为还不会变；要等生产接线后才生效（见文末）。
- 不新增存档字段，不新增随机消耗。几何查询本身不抽随机数，跳跃的结果写进已有的 `brain.speed`。

## 各调用点

| 规则         | 位置                                                                            | 有几何时的做法                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 跳跃       | `EnemyAi.landing`（起跳那一步）                                                 | 用 `sweepCircle(walk\|land)` 截到第一个阻挡；终点用 `canOccupy(land)` 检查，不行就沿原方向每次退 2 单位，最差原地跳。`stageView` 的公式不变 |
| 2 铲爪蛙     | 不改                                                                            | 地下阶段本来就是有碰撞的身体，出土点就是当前合法位置；只加测试断言                                                                          |
| 3 视线       | `CombatWorld.aiLos`：`AiHost.lineOfSight`（远程射程判断、Boss 弹幕）与 `lashAt` | `traceSegment(LOS)`；凹口外的房外区域也会挡住。玩家武器仍用旧的 `los`，属于武器机制，以后另行迁移                                           |
| 4 冲撞       | `crashInto`                                                                     | 先保留撞碎前方已落石块并眩晕；否则沿冲撞方向 `sweepCircle(walk)`，首次命中是 boundary 就只停下，其余（内墙、柱、桶、什么都没碰到）都眩晕    |
| 5 召唤与分裂 | `spawnAround`                                                                   | 候选位置用子体完整身体做 `canOccupy(spawn)` 检查，代替原来的 `los`；不合法就退回施法者位置。每只仍只抽一次随机数，数量不变                  |
| 6 落石       | `dropRocks`                                                                     | 十字 `lineOfSight` 检查换成 `canOccupy(rock)`；尝试用尽时跳过这一块，也不抽它的错开时长                                                     |

## 与旧规则的差异（接线生效后）

- **矩形房、无障碍时与旧规则相同**：12 种普通怪的逐秒存档完全一致（见下面的测试）。
- **有意的行为变化**，都已写入 ADR 0039：
  - 奶怪贴外墙冲向靠墙柱，从「不晕」变为「晕」；
  - 墙角召唤不再把子体放到房外，改为放在施法者身上；
  - 落石不会落进墙或柱，也不会和已落地的石块、立着的桶重叠；所有尝试都不合法时少落这一块；
  - 凹形房间里，隔着房外区域看不见玩家，不会开火。
- 这些变化会让新旧构建的战斗轨迹不同。跨构建读档仍按既有规则退回楼层入口。

## 本地验证

新增 `tests/unit/sim/aiGeometry.test.ts`，共 23 项。物理用最小积分代替 Arcade：新位置能被几何容纳（贴合合法）才写回。

- **矩形等价**：巨爪、苇腿、陶甲、鼓腮、菌冠、角冲、蓄跳、膨爆、围舌、铲爪、鳍舞、烟管 12 种，有几何与无几何各跑 20 秒，每秒的完整存档逐字节相同。负卵蛙、腹囊蛙和奶怪的召唤、分裂、冲撞、落石在墙边本来就有意不同，单独测试。
- **视线**：凹口两侧，有几何时菌冠蛙 8 秒内不开火，旧规则会隔墙开火；柱子挡住时不开火，绕到柱子旁边就恢复。
- **跳跃**：
  - 路上有柱子时，落点被截到柱前（x = 90 − 6）；实际落点与起跳时的预计落点相差不超过一步位移，并且能落地；
  - 贴着墙起跳仍然能跳出去；
  - 终点被禁止落地时，每次退 2 单位（80 → 30），全部不行就原地跳；起跳那一步的 AI 随机状态与不退回时相同。
- **冲撞**：贴外墙冲向靠墙柱判为 `stun`（旧规则在同一场景判为 `crash`）；冲向外墙判为 `crash`。
- **召唤**：负卵蛙贴在墙角召唤，子体数量和 AI 随机状态与旧规则相同；每只子体都在合法位置或施法者身上，旧规则会放到房外。
- **落石**：有两根柱子的房间里，奶怪三分之一血量时 25 秒内新出现的每块石头都能 `canOccupy(rock)`。所有尝试都不合法时，那一步的 AI 随机抽数正好是 7 块 × 8 次 × 2 − 1，没有石块生成。
- **铲爪蛙**：L 形房、凹口加柱子的房，各三个玩家位置，每次出土都能容纳身体（总共超过 10 次）。

本地替身环境：`tests/unit/sim/*` 与根目录单测全部通过，`tsc` 没有新报错。ESLint、Prettier 3.9.10、vite 构建、e2e 请 GPT 用完整的 `npm run check` 复核。
