## 100 秒锁步压力记录

6000 个 1/60 秒真实物理步；持续补充至 30 个敌人，玩家使用环射武器并补充能量。显示对象在初始化后没有增长，31 个 sim 实体记录反复复用。

| 计数                 |      桌面 | 手机横屏模拟 |
| -------------------- | --------: | -----------: |
| 总生成敌人           |        98 |           98 |
| 不同实体记录对象     |        31 |           31 |
| 同时活跃子弹峰值     | 338 / 500 |    338 / 500 |
| 同时活跃瞬时反馈峰值 |  43 / 100 |     43 / 100 |
| 模拟时间             |     100 s |        100 s |
| 显示对象数增长       |         0 |            0 |

这是加速锁步的容量与生命周期验收，跳过逐帧实际绘制，不能换算成渲染 FPS。另有 500 子弹满池/超限/释放的物理 fixture，以及 1000 次规则实体重生身份检查。仍需真机 30 分钟与实际 draw call/FPS 测量。
