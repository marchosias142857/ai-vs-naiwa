# #117 图片 UI 与天赋树验证

基线：main `ca9a2d057fa187e156a514f802c8d205c2b2d56e`（#142 已合并）。本项只改变界面表现；`src/sim`、`src/data`、`src/services`、输入控制器、PauseState、combatPause 和世界美术均无修改。未新增依赖或共享契约，未启动 #118/#119/#134/#141。

## 实现与资源

- 开屏、设置、主城、HUD、地图、暂停、布局编辑、图鉴、天赋、奖励/商店/结算、加载、横屏与 PWA 提示共用实际图片框架和图标。动态文字继续走 i18n；原生按钮、disabled、焦点及 aria 状态保留。
- 天赋节点用星标、金币、锁、勾区分可购、点数不足、前置未解锁、已满级；详情和购买按钮解释同一状态。保留依赖关系、价格、等级、档案、重置确认和新局生效规则。568×320 英文为分支保留 210px，实际横纵滑动可查看完整树；矮屏标题不悬浮遮挡节点。
- InputImages 固定创建 11 张图片，移动/攻击/暂停按钮沿用 INPUT_UI 和可保存布局的尺寸。倒计时直接读取原 PauseState.remaining，不拥有第二套时钟；图片帧只在 3/2/1 改变时切换。
- 3 张 imagegen 原稿与精确提示词在 `art-src/ui`；导出脚本只扫描 alpha、按实测格裁切、等比缩放及打包。运行时为 6 张 128² 九切片框架、1 张 384² 图标图集（36 格）和 1 张 384×256 触控图集（6 格）。
- 8 张运行图合计 **651,126 bytes**，最大单图 **286,027 bytes**，解码 RGBA 合计 **1,376,256 bytes（1.3125 MiB）**。原稿不进入 public/预缓存。切片、文件尺寸和 SHA-256 见 [manifest](../../art-src/ui/manifest.json)。
- 原有测试夹具补载同一 UI 图集，Vite 夹具服务器提供 public 图片；不在生产路径增加替代图片。

生成与扩充规范见 [UI_ART_STYLE](../UI_ART_STYLE.md)，实景见 [20 张截图](image-ui/README.md)。截图来自生产构建，不是概念图。

## 验证范围与异常记录

- 图片 UI 新用例检查真实 border-image 解码、焦点/禁用态、天赋四状态、图片连线、重置取消、HUD/地图/暂停/编辑器以及圆形控件尺寸。小屏用真实滚轮或 CDP 触摸验证横纵滚动，检查英文文字与窗口边界。
- 原天赋用例复核迁移、失败写盘、连续购买、退款确认、新局配置、同版本续玩、更新结束旧局且保全档案、中英文与手机交互。
- PWA 用例在子路径安装后断网，逐个 fetch 并 createImageBitmap 解码全部 8 张新图；另测连续两次更新和未保存布局。桌面/手机四项已通过。
- 初次并行回归中，PWA 连续更新两端曾在原 5s 等待内停留于页面加载；停止并行负载后，桌面使用原等待设置单独通过，随后四项 PWA 在本机 15s 等待配置下全部通过。未为此改动更新逻辑或放松业务断言。
- 新增 568×320 检查最初发现英文节点被挤压；固定窄屏列宽并开放横向滚动后通过，随后按截图移除矮屏悬浮标题遮挡。
- 扩展回归的角色图集测试发现原有响应读取与 `page.reload()` 竞争：CDP 尚未取完图片字节，导航即销毁了响应标识。测试现在先 await 两张图集响应，再刷新；原 SHA、纹理、受击与死亡断言全部保留，游戏代码未改。

## 手动复核

1. 本地 `npm run build && npm run preview`，打开 `/?seed=42`，查看开屏/设置中英文、禁用续玩和键盘焦点。
2. 进入主城，打开图鉴；移动至祭台并打开天赋树，查看购买条件、选择详情、重置确认与取消。在 568×320 英文下左右/上下滑动三个分支。
3. 进入地牢，打开地图、暂停和布局编辑，拖动/缩放控件并保存，再次打开确认位置。触屏双指移动和射击，检查新圆盘与实际命中区。
4. 同版本续玩检查 3/2/1 冻结与恢复，安装 PWA 后断网重开，确认新框架、图标、圆盘和天赋完整加载。
