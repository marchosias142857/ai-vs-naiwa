## 1. 定位

- **名称**：AI 大战奶蛙（AI VS NAIWA）。
- **核心幻想**：玩家操控 AI 娘，闯入奶蛙怪物的巢穴，一局 20–30 分钟，每个房间都是一场短促的弹幕战，每局拿到的武器和 Buff 都不一样。
- **视角与操作**：俯视角、自由移动、房间制战斗；手机横屏游玩。
- **平台**：手机浏览器（iOS Safari 16.4+、Android Chrome）安装为 PWA；桌面 Chrome/Edge/Firefox/Safari，键鼠或手柄。完全离线、无服务器。

### 体验支柱（取舍以此为准）

1. **爽快射击**：移动零延迟；命中闪白、屏幕微震、击退、子弹残影。
2. **构筑随机性**：武器 × AI 娘技能 × Buff 产生组合。
3. **手机友好**：双摇杆 + 自动瞄准，可随时暂停与续玩。

### 体量

| 内容         | MVP（M4）   | 1.0 目标                         |
| ------------ | ----------- | -------------------------------- |
| 可玩 AI 娘   | 1           | 6                                |

**明确不做**：联机、内购与广告、账号与云存档、关卡编辑器（用 Tiled）、3D。

## 2. 一局的流程

1. 大厅选 AI 娘 → 进入 1-1。
2. 每小关是 6–9 个房间组成的地图，房间之间走廊相连。
3. 进入战斗房 → 门锁上 → 1–3 波刷怪 → 清完开门，掉落能量 / 金币，概率出宝箱。
4. 找到传送门进入下一关；每个大关最后一层是 Boss 房。
5. 死亡或通关 → 结算（统计、局外货币）→ 回大厅。

## 3. AI 娘属性

| 属性        | 初始值（示例） | 规则                                           |
| ----------- | -------------- | ---------------------------------------------- |
| 生命 HP     | 6              | 归零死亡，只能靠血瓶、Buff 恢复                |
| 护甲 Armor  | 5              | 先扣护甲；3 秒未受伤后每 1 秒回 1 点           |
| 能量 Energy | 200            | 大多数武器每发消耗能量；为 0 时只能用 0 耗武器 |
| 移速        | 90 像素/秒     | 角色数据决定                                   |
| 主动技能    | 冷却 8–15 秒   | 每位 AI 娘 1 个                                |

受伤后 0.6 秒无敌帧并闪烁。

## 4. 武器

- 同时携带 2 把，一键切换；地上武器靠近后按「交互」交换。
- 字段：`id`、品质（白/绿/蓝/紫/橙/红）、类型（手枪、步枪、霰弹、狙击、激光、法杖、近战、投掷）、伤害、射速、能耗、散布、弹丸数、弹速、射程、暴击率、穿透、弹道模式、命中效果（火、毒、冰、电、爆炸）。
- 弹道模式用注册表：`single`、`spread`、`burst`、`beam`、`melee_arc`、`orbit`、`homing`、`bounce`、`charge`。新武器 90% 只写数据。
- 自动瞄准：手机默认锁定射程内最近且可见的敌人；桌面用鼠标瞄准，可在设置里开自动瞄准。

## 5. 关卡与房间

- 5×5 网格生成；起点到传送门主路径 5–7 间，挂 1–3 个支线房。
- 房间尺寸几档（15×15、19×19 格，一格 16 像素），内部布局来自 Tiled 模板，随机抽取并可镜像。

| 房间   | 出现规则     | 内容              |
| ------ | ------------ | ----------------- |
| 起点   | 每关 1       | 安全              |
| 战斗   | 主路径大部分 | 锁门刷怪 1–3 波   |
| 宝箱   | 每关 1       | 武器宝箱          |
| 商店   | 每关 0–1     | 金币买武器、血瓶  |
| 祝福   | 每关 0–1     | 付金币或血换 Buff |
| 精英   | 每大关 1–2   | 强化怪 + 好奖励   |
| Boss   | 大关最后一层 | 打完 3 选 1 Buff  |
| 传送门 | 每关 1       | 下一关            |

## 6. 奶蛙怪物

- 怪物 = 数据（血量、移速、接触伤害、掉落）+ AI 行为（状态机）+ 攻击模式（复用武器弹道注册表）。
- 基础行为：`wander`、`chase`、`keep_distance`、`charge_dash`、`turret`、`summoner`、`suicide`。
- 出场前地面 0.6 秒红圈预警。
- Boss 多阶段：血量 70%、40% 切换，每阶段 2–3 种弹幕。

## 7. Buff 与经济

- **Buff**：每过一个大关 3 选 1，本局永久；以修饰器叠加到属性，不改原值。
- **局内**：金币来自怪物与宝箱，商店、祝福消费，死亡清空。
- **局外**：宝石（结算按进度发放），解锁 AI 娘、升级天赋，存本地。
