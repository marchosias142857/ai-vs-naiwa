## 当前：架构完成，合作细化与性能优化

负责人于 2026-10-25 确认整体架构完成，并已在自己的设备上验证当前版本。后续在现有项目上细化玩法、内容、美术与性能；GPT 和 Claude 按 AGENTS.md 当前分工协作，不重建项目。

当前 main 基线 `b525516` 已包含 #93 怪物招式与奶怪 Boss、#94 的 13 把新武器和特殊机制（共 25 把）、#95 的楼层主题、内墙和五类机关。#94、#95 已依次合并，#95 合并前已 rebase 并将 base 改为 main；合并后的 Git tree 与复测版 `be5db3a` 相同。

已有标题 → 最小主城 → 三层地牢 → Boss → 结算，以及死亡/退出/续玩、双摇杆、键鼠/手柄、全屏地图、跟随镜头和可保存的 UI 布局。主城不持武器，只设一扇地牢门；返回主城保留旧冒险，开始新冒险才经确认替换存档。

本轮按负责人要求同步文档并优化装饰特效：复用纹理、活动槽位遍历、分类生成预算、屏外省略与闪电形状缓存，见 [性能优化记录](testing/fx-performance.md) 和 ADR 0033。角色、弹体、危险预警、输入、锁步和存档规则维持现有行为。

上表继续作为长期路线，不代表所有条目都已实现或当前自动分配：局外成长、更多内容、Tiled 管线、音乐等按负责人后续需求推进。负责人已完成自己的设备验证；目前未提供量化 FPS、draw call 或 30 分钟测试记录，不据此填写性能数值。旧本地报告的 WebKit 系统库缺口单独保留，不将其表述为负责人尚未验收。

历史交付与截图见 [demo 记录](testing/demo-production-acceptance.md)、[高清表现](testing/hd-presentation.md)、[主城入口](testing/town-entry.md)。远端自动 CI 保持关闭，PR 由负责人合并。
