4. 新增带 schema 的身体中心、标准持握点、逐帧持握点、武器握把和枪口数据；近战契约与 ADR、锁步命中、挥动状态存档。
5. 大肥鱼动画与独立武器；左右翻面、握把旋转、朝上背后遮挡，统一身体中心命中区。
6. 实际 PNG 美术、原创怪物与房间、菜单和 HUD、武器与掉落、打击感与原创音效；图集与离线资源预算。
7. 自审与完整流程验证：开局、探索、射击/近战、升级、Boss、死亡/胜利、结算、退出续玩、移动端多指与离线。

## 自审必须核对

- sim 不依赖 Phaser/game/services；随机分子系统 fork；玩法和几何数据带 schema。
- 所有玩法按 WORLD_STEP 推进；动画持握点不进入 sim，弹丸出生使用固定标准点。
- 角色/子弹/特效/武器显示对象预热复用；回收与场景清理不遗漏监听。
- 存档逐字段校验，旧档兜底原因明确，挥动中存读档与不中断按相同步输入严格一致。
- 相邻身体圆、手动瞄准、墙体、翻面、四向武器遮挡、第一发方向有真实浏览器覆盖。
- 小 PR、自审说明、CI 全绿、截图与资源来源。不得把视觉截图或模拟手机测试描述成真机验收。
