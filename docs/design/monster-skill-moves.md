# #101 怪物技能动画定稿方案

起草：Claude，2026-10-27。依据 GPT 的[接入审计](monster-skill-animation.md)（PR #112）定稿，契约见 [ADR 0038](../adr/0038-monster-move-progress-view.md)。本文是动画接入 PR 的设计依据：表格里的「替代建议」以本文为准，审计里的来源分类和验证清单继续有效。

## 1. 原则

- **sim 决定何时，画面只读进度。** 帧、形变和提示的强弱都由 `stage`、`stageTime / stageSpan`、`aimLocked`、`landX/landY` 推出，不自建技能时钟，不靠动画回调触发任何事。所有时长、冷却和伤害保持不变。
- **三层反馈：**
  1. 身体：现有少帧图配合简单形变，包括压扁/拉伸、后坐、抖动、膨胀，不另画新造型；
  2. 方向：锁定那一刻要有一个可见的变化；
  3. 地面：攻击会在施法者以外的位置生效时，用落点影子、路径擦痕、范围刻度标出位置。
- **不用红色描边圆。** 出生提示的红圈保留，技能提示必须一眼能和它分开。技能提示统一用奶白/淡黄高光（`#fff1c2` 附近）和地面暗影，危险程度靠形状、填满程度和节奏表达，不靠红色。
- **必要与装饰分开：**
  - 必要反馈不进 FxBudget，读档首帧就能完整画出：身体动作、方向提示、落点影子、范围刻度、石块影子、眩晕星星；
  - 装饰进 FxBudget，超出预算直接省略：扬尘、碎屑、汗滴、速度线、发光脉动。
- **保持现有美术：** v4 造型和精度不变。每种怪现有 2 帧前摇、2 帧出招、2 帧收招，加上弹簧蛙 4 帧腾空、铲爪蛙 4 帧地下、鳍舞蛙 4 帧旋转、奶怪的腾空/旋转/狂笑。形变以贴图原点（ADR 0037 的身体锚点）为中心缩放，像素对齐规则不变。

## 2. 选帧与形变的通用写法

```
p = stageSpan > 0 ? stageTime / stageSpan : 0      // 0～1
只播一遍的动作（windup / attack / recover / air）：frame = min(n - 1, floor(p * n))
循环动作（spin / buried）：frame = floor(stageTime / seconds) % n
ease = p * p                                         // 前摇越到后面越急
```

- 本文的「后坐 k px」是沿 `aim` 反方向平移，「抖动 k px」是按 `sin(stageTime × 频率)` 左右摆动，振幅只取整数像素。
- 形变只用于画面，不改变物理代理和身体圆。

### 3.3 落石（砸地与石块雨共用）

`HazardLayer.drawRocks` 里的红圈和红色填充去掉，改为下面三部分：

- 整个 `fall` 期间（从 t = 0 起，不再等到 t > 0.35）在落点画地面暗影，透明度 0.25→0.7，大小 0.5→1.0 倍石块直径；同时从 t=0 起画透明度 0.9 的奶白四角括号，位置随 t 从 1.3 倍 r.radius 收到 1.0 倍，属于必要提示、不进 FxBudget。四角不连接成整圆、不用红色，与出生圈及膨爆放射刻度区分。最后 0.15 s 边缘加一圈奶白小尘点（尘点为装饰）；
- 石块从高处落下（现有画法）；
- 落地后变成障碍、崩解（现有画法）。

读档后直接按 `RockView.time / fall` 恢复。

## 4. 状态切换

| 情况                   | 画面                                                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 受击                   | 仍按现有规则：只在 idle/move/recover 时叠受击帧；前摇、出招、腾空、钻地不被打断，也不重置进度                            |
| 冻住                   | 停在当前帧和当前形变，染冰蓝；方向、落点、范围提示保持显示，停止脉动；`CombatFeedback` 与 `HazardLayer` 统一按此规则处理 |
| 中断（撞墙、满额不孵） | 直接按新阶段显示；满额不孵时不画孵化效果                                                                                 |
| 死亡                   | 立即停止该怪的全部技能提示，播放死亡动画；膨爆蛙自爆走现有爆炸与死亡                                                     |
| Boss 阶段变化          | 阶段只影响后续招式，进行中的动作照常播完                                                                                 |
| 换房                   | 实体和石块都已清掉，表现层不保留残影                                                                                     |
| 暂停 / 后台            | sim 不推进，画面自然静止，恢复后接着播                                                                                   |
| 读档                   | 首帧按视图字段与 `RockView` 恢复，不等待事件                                                                             |

## 5. 接入顺序建议（GPT）

1. `EnemyArt`：技能阶段改用进度选帧并加形变，删掉这些阶段对 `PoseClock` 的依赖。
2. `HazardLayer`：
   - 加爪痕、擦痕、口水点、人字箭头、落点影子、范围刻度、石块影子；
   - 冻结时显示提示但不脉动；
   - 全部用固定容量的 Graphics 绘制或复用纹理。
3. 上面两步全部接好后，在同一个 PR 里删掉 `CombatFeedback` 的技能 `warning` 圈，以及 `HazardLayer` 的舌击红虚线、冲撞红通道、自爆红圈、落石红圈。出生圈、机关、区域、弹体、光束和实际爆炸保留。
4. 图鉴中英文的招式说明对照新动画微调，例如「看到它压低身子」「脚下出现擦痕」。
5. 逐招提供 GIF 或关键帧，覆盖前摇首帧、锁定、前摇末帧、生效首帧、收招，以及冻结、读档、密集战斗时装饰预算为 0 的截图，交负责人真机验收。

`ActorView.warning` 暂时保留。等红圈全部移除后，如果没有任何使用者了，再另开清理任务。
