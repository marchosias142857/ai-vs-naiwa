# 美术与资源规范

## 当前 demo 的高清像素素材

本节按负责人 2026-10-24 的要求覆盖下方历史占位尺寸。逻辑世界为 480×270；渲染缓冲高度为 1080，主城/地牢宽度可按横屏安全区扩展，标题页保持 1920×1080。房间相机为原显示比例的 1.5 倍，贴图同一源边与滚动均按实际相机 zoom 对齐。像素风来自 PNG 内的色块和轮廓，不把整张画面先压到低分辨率。详见 ADR 0024、0027、0028。

- 大肥鱼最终按负责人提供的《元气骑士》两张图匹配粗颗粒像素密度，身体约 24–32 原生像素高；保留蓝发、白帽、白围裙与鲸鱼尾巴，优先可爱与轮廓可读性。待机 6 帧上下摆尾，行走 8 帧交替迈步；受击与死亡保留选定的原动作。
- 原图的像素坐标、身体中心、袖口握持点与时长集中在 `src/data/art.ts`。新旧动作的源尺寸不同，用 `scale` / `reactionScale` 校准显示比例。
- 角色身体不画手；武器握把附一块单色长方形作为手，无手指或关节。手随武器旋转、翻面；全部游戏图集使用 NEAREST 采样，字体独立保持高清。
- 每个 PNG 小于 2 MiB，并经 PWA 离线用例检查；来源及完整生成提示见 `art-src/demo/README.md`。
- 常规动作可配置固定 `face` 子帧，复用同一面部并对齐同一源图边缘：未翻转为左上角，翻转后为右上角；周围身体继续逐帧显示，受击/死亡不使用固定面部。非整数缩放时不要把左右朝向都对齐左边，否则眼睛取样不会严格镜像，见 ADR 0027。

### 新增可玩角色

1. 在 `src/data/characters.ts` 注册玩法 ID 与属性。
2. 在 `src/data/characterArt.ts` 的 `CHARACTER_ART` 同 ID 注册图集 key、PNG 文件名、帧矩形、pivot / grip、时长与四种动作序列；每个角色用独立 key。动作帧不要求使用大肥鱼的名称。
3. PNG 放进 `public/assets/demo/`，分别配置常规 / 反应图集及比例，也可共用一个图集。身体原点、武器握持点和判定半径分别校准。
4. 运行 schema、资源边界、动画与 PWA 验证；补充来源和截图。加载与渲染会自动使用角色配置，无需增加按角色判断的分支。选人界面、角色数值和内容仍须单独设计。

## 历史占位规范

开发全程不等美术：M1–M4 用代码生成的占位图（`src/game/assets/placeholders.ts`），美术到位后按本规范替换，**只换图片不改代码**。

## 尺寸

| 资源           | 尺寸（像素）             | 说明                             |
| -------------- | ------------------------ | -------------------------------- |
| 地面 / 墙瓦片  | 16×16                    | 墙体顶面 + 正面两层              |
| AI 娘 / 普通怪 | 帧 24×24（本体约 16×20） | 脚底中心为原点                   |
| 精英怪         | 32×32                    |                                  |
| Boss           | 48×48 – 96×96            |                                  |
| 武器           | 宽 ≤ 32，高 ≤ 16         | 握把为旋转原点，数据里填 `pivot` |
| 子弹           | 4×4 – 12×12              | 敌方子弹统一偏红/紫              |
| UI 图标        | 16×16、32×32             |                                  |
| PWA 图标       | 192、512、512 maskable   |                                  |

- 调色板：负责人提供 32–64 色，放 `art-src/palette.hex`。
- 可读性第一：地板低饱和，角色与子弹高饱和；敌方子弹在任何地板上一眼可见。
- PWA 图标：maskable 版本要单独出图，主体放在中心 80% 圆形安全区内，四周铺满不透明背景；普通 192/512 图标可以画得更满。当前占位图两者是同一张，主体刚好落在安全区内。

## 命名与动画

- 文件名 `类别_名称_动作`，全小写下划线：`ai_girl_a_run`、`naiwa_green_die`、`bullet_small_yellow`。
- 角色动画：`idle` 4 帧、`run` 6 帧、`hit` 1–2 帧、`die` 4–6 帧；只画朝右，朝左代码翻转。
- 怪物动画：`idle`、`move`、`attack`（可选）、`die`。默认 10 fps。

## 交付流程（M5 起）

1. 原文件（`.aseprite` / `.png`）放 `art-src/<类别>/`。
2. `npm run art`：打包图集到 `public/assets/atlases/`，重新生成 `src/game/assets/keys.ts`。
3. 数据里把占位 key 换成新 key，提交 PR。

音效 `.ogg` + `.m4a` 双格式，单个 ≤ 50 KB；音乐流式加载，不进预缓存。
所有外部素材在本文件末尾登记来源与授权。
